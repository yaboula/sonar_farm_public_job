# World indicator assets

`slot-marker.svg` and the optimized `slot-marker.png` runtime derivative use the **Grains / fill** icon from [Phosphor Icons](https://phosphoricons.com/), copyright 2020 Phosphor Icons, licensed under the MIT License. The same MIT license is distributed with `@phosphor-icons/react` in this resource's web packages.

The PNG is a 128×128 transparent monochrome raster. FiveM applies semantic color and distance alpha at draw time, so one texture serves every slot state.
